# Pokémon Sleep icons

Berry, ingredient, and specialty icons are copied from the public [Neroli’s Lab asset collection](https://github.com/nerolis-lab/nerolis-lab/tree/647ddf8167fb8ae2295769ea70914af125f16a79/frontend/public/images), pinned to commit `647ddf8167fb8ae2295769ea70914af125f16a79`. Original filenames are retained; `badges/` uses its `unit/` icons. Pokémon Sleep artwork belongs to its respective rights holders. This is an unofficial personal fan collection.

`../asset-data.js` joins English names to these icons and the public game subskill rarity table: 1 = normal, 2 = silver, 3 = gold. Unknown names have no inferred icon or rarity. Locked status is independent of rarity. No sleep ribbon or other earned achievement is inferred.

Candy and item artwork is copied locally from [RaenonX's public artwork CDN](https://pks.raenonx.cc/en/item/overview). `inventory-sources.json` records exact source URLs, public reference versions, and SHA-256 checksums. The 193 WebP files cover all named non-ingredient inventory entries in the October 2 snapshot, plus Dream Shards. Species candy uses the catalog's explicit `pokemonCandyDataMap.imageName`; regular items join the game's `item_name_data` ID and exact localization key to the catalog's `itemMap`. Pokémon incense uses the linked target Pokémon's type, matching the catalog's incense icon component. Unresolved item names remain without an inferred icon. Art belongs to Pokémon / Nintendo / Creatures / GAME FREAK; RaenonX hosts the extracted artwork.
